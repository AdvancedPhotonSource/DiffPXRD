# Paper Figures

`reproduce/figures.py` renders Figures 1-5 and Supplementary Figure S1 from a source-data
packet. It does not fit diffraction patterns, rerun timings, download data, or
read an institutional filesystem. It preserves the accepted figure layouts and
numerical inputs. The same packet supplies `reproduce/tables.py`.

```bash
python -m pip install -e '.[reproduce]'
python reproduce/figures.py --data-dir /path/to/plotting-packet \
  --icsd-structure /path/to/licensed/427040.cif \
  --neutron-tables /path/to/my_neutron_tables.npz --output-dir results/figures
```

The output directory must not already exist. To render a subset, add
`--figures 2 3 4 5 S1`. Figure 1 PDF and PNG export additionally requires
`rsvg-convert` from librsvg. Its standalone editable SVG is copied unchanged;
the other five figures are rebuilt with Matplotlib. All figures are exported as
SVG, PDF, and 600 dpi PNG. `rendering.json` records completion and the names
of consumed inputs. PDF metadata and font-renderer differences can prevent
byte-identical exports across environments.

## Figure 2 Structure

The public packet contains ICSD identifiers, not licensed ICSD coordinates.
The structure inset in Figure 2 requires your own authorized copy of **ICSD
entry 427040**, Ho4RuBr5, with 80 sites (Ho32 Ru8 Br40), supplied through
`--icsd-structure`. A Materials Project structure is not a substitute. To render
the other figures without this entry, use `--figures 1 3 4 5 S1` and omit the option.

The option accepts either a single-structure CIF or compact JSON with
`lattice_matrix` (3 by 3, in angstroms), `species` (80 element symbols),
`frac_coords` (80 by 3 fractional coordinates), and optional `site_properties`.
JSON may also declare `icsd_id`; if an identifier is present in JSON or the
CIF's `_database_code_ICSD` field, it must be `427040`. Formula, species counts,
cell validity, and site count are checked, but these checks alone cannot
authenticate the database origin of a file.

Use the same 80-site cell setting, axis orientation, and origin as the ICSD
target used for the paper. CIF reading expands the supplied symmetry without
primitive-cell reduction or conversion to a standard cell; it disables
fractional-coordinate rounding. Equivalent choices of origin or axes can
change the inset, so exact visual reproduction requires the original compact
coordinate export. The renderer records the supplied file's SHA-256 checksum
and identity checks in `rendering.json`; it does not change any recorded
diffraction profiles, errors, or timings.

## Figure 5 Reference

Figure 5a also needs `--neutron-tables`, prepared from your own transcription
of Kong et al. Tables S1-S2. Follow [the preparation instructions](ca3ti2o7_neutron_tables.md).
No neutron coordinates, reference cell lengths, or mapped Acaa reference are
in the plotting packet. It contains our fitted positions; the renderer obtains
the open reference sites and reference cell from your prepared file.
Use `--figures 1 3 4 S1` to render without either external structural input.
All supplementary tables and saved supporting checks need neither input.

## Plotting Packet

The packet is separate from the code distribution. Access to the original data
is documented in the deposit's `SOURCES.md`. Original diffPXRD outputs use the
code's BSD `LICENSE.txt`; third-party terms remain separate.
Verify the deposit with `sha256sum -c checksums.sha256`
before extraction. The renderer fails if any required file is missing; it never substitutes
illustrative data or earlier results.

The root `figures.json` declares schema `diffpxrd-paper1-plotting-inputs-v2` and a
`files` mapping from relative filenames to sizes in `bytes`. Files are grouped
by their reader-facing names:

| Figure | Inputs |
| --- | --- |
| 1 | `overview.svg` |
| 2 | `engine.json`, `engine_profiles.npz`, `engine_complete_timings.csv`, `engine_batch_statistics.csv`, `engine_reference_statistics.csv`, `cucr2o4.json`, `cucr2o4_profiles.npz` |
| 3 | `nca_trajectories.npz`, `nca_settings.json`, `nca_summary.json`, `nca_timing/` |
| 4 | `lisulfur_trajectories.csv`, `lisulfur_metrics.csv`, `lisulfur_summary.json`, `lisulfur_profiles.npz` |
| 5 | `ca_trajectories.csv`, `ca_states.csv`, `ca_measured_ratios.csv`, `ca_predictions.csv`, `ca_display.npz` |
| S1 | `ca_doublet_fits.csv`, `ca_transition_display.npz` (all 480 measured patterns) |

## Supplementary Tables

```sh
python reproduce/tables.py --data-dir /path/to/source_data --output-dir results/tables
```

Five CSV/LaTeX pairs are generated: `table_1_accuracy`, `table_2_derivatives`,
`table_4_reflection_windows`, `single_timing`, and `repeated_timing`. The retained
table numbers are filenames, not SI numbering. Obsolete CuCr2O4 refinement-time,
Ca ratio-scan, and Ca profile-residual tables are not generated by this command.

The timing tables use `engine_complete_timings.csv`, `engine_peak_counts.csv`,
`engine_repeated_timings.csv`, and `engine_reference_timings.csv`. They pair CPU
and A100 observations by structure identifier before computing speedups. Timing
CSVs contain unrounded statistics; LaTeX uses the manuscript's displayed precision.

The packet also supplies the Lato regular and bold fonts and their license under
`fonts/`. Array files contain numeric or fixed-width string arrays and are read
without pickle. Stored values retain the source precision. The Ca heatmap has
346 measured states and 120 angular bins; empty bins remain missing rather than
being assigned artificial intensity. Atomic coordinates are frozen in angstroms,
and the visual displacement amplification is unchanged from the accepted figure.

These commands reproduce presentation of the recorded results. The NCA and
Li-S noise ensembles and Ca trajectory are not regenerated by rendering, and
the plotted timing values describe the originally recorded hardware rather than
the machine used to draw the figures. Use the corresponding reproduction
commands to run new calculations.
